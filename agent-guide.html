AI Agents: 개념부터 노코드 구축까지

출처: Anatoli Kopadze (@AnatoliKopadze), 2026-06-08
Everyone is talking about AI agents. But if you ask most people what an agent actually is, you get a vague answer about 'AI that does things autonomously.' The real picture is more useful than that. Agents are not a category. They are a spectrum.

Agent vs 일반 채팅

질문 한 번에 답변을 받는 것은 채팅입니다. 토픽 탐색, 초안 작성, 파일 저장까지 사용자 개입 없이 끝까지 수행하면 Agent 입니다.

The difference is not the model. It is the structure around it.

Agent의 3가지 필수 구성 요소

1. Self-directed tools

검색, 파일 시스템, 코드 실행, 외부 API 등 스스로 도구를 선택해 사용

2. Persistent memory

세션 간 기억 유지. 한 번의 대화로 끝나지 않도록 상태 저장

3. Autonomous loop

목표 완료까지 자동 실행. 한 번의 응답으로 멈추지 않는 실행 루프

자율성 스펙트럼

Lv.1Basic Chat

일회성 질의응답, 도구 없음, 진행 목표 없음

Lv.2Tool-Enabled LLM

도구 사용을 스스로 판단, 단계별 지시 없이 검색·생성 수행

Lv.3Multi-Step Workflow

상위 목표를 단계로 분해하고 검증하며 최종 결과물 산출

Lv.4Fully Autonomous

스케줄 실행, 입력 감시, 외부 서비스 호출, 사람 개입 없이 완료

5가지 구축 가능한 Agent 유형

Research Agent

다중 소스 리서치로 핵심 인사이트를 구조화된 요약으로 전달

Writing Agent

사용자 톤·형식·대상에 맞는 콘텐츠 초안부터 수정까지 자동화

Code Agent

기능 설명을 받아 코드 작성·실행·디버깅·반복을 자율 수행

Business Agent

이메일 초안, 고객 요청 처리, 리드 검증, 리포트 자동 생성

Personal Agent

일정 관리, 태스크 정리, Daily briefing, 수동 기획 업무 대체

노코드 구축 가이드 요약

Telegram Bot + Claude Code 기준, 구축 시간 약 10~20분

  • 필요 조건: Claude API Key, Telegram Bot Token, Linux VPS (1vCPU/1GB RAM)
  • 설치: npm i -g @anthropic-ai/claude-code
  • 모델 추천: Sonnet 4.6 (일상용), Haiku 4.5 (저비용), Opus 4.8 (고난도 분석)
  • 구성 요소: 봇 성격 정의 시스템 프롬프트, 백그라운드 실행, 세션 간 기억, 웹 검색, 노트 저장, 계정 제한, 비용 추적, 스케줄러
