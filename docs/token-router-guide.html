token-router

Gemma4 2B 로컬 모델로 Codex, Claude Code 토큰 비용을 99% 절감하는
무손실 로컬 컨텍스트 라우터

MIT License Python 3.10+ Ollama + Gemma4

핵심 철학

“탐색은 로컬에서 무료로, 추론은 클라우드에서 고성능으로”

2,000줄이 넘는 로그나 거대한 소스코드를 클라우드 LLM에 통째로 넣으면 토큰이 낭비되고 지연이 발생합니다. token-router는 요약하지 않고 로컬 Gemma4 2B가 필요한 라인 번호(좌표)만 찾아내 원문 그대로 오려냅니다. 클라우드 모델은 노이즈 없는 고밀도 원문만 받아 추론에 집중합니다.

3단계 아키텍처

단계엔진역할출력
1. 탐색 Ollama + Gemma4 2B (로컬) 질문에 맞는 정확한 라인 좌표 탐색 JSON 라인 범위
2. 추출 router.py (Python) 디스크에서 원본 그대로 텍스트 조각 오려냄 Raw unedited text
3. 추론 클라우드 LLM (Claude Code / Codex) 노이즈 없는 고밀도 원문으로 디버깅/리뷰 고신뢰 답변

3가지 라우팅 모드

📝 error_log

배포 로그, 에러 트레이스 등에서 키워드 + 꼬리 부분을 추출

router.py error_log –file deploy.log –query "timeout"

📚 heavy_code

대용량 소스코드에서 버그/핵심 로직/구조만 추출

router.py heavy_code –file module.py –query "race"

⚙️ agent_context

긴 CLAUDE.md / AGENTS.md / .cursorrules 에서 작업 관련 규칙만

router.py agent_context –file AGENTS.md –query "deploy"

설치

  1. Ollama 설치 및 Gemma4 2B pull
    curl -fsSL https://ollama.com/install.sh | sh
ollama pull gemma4:e2b-it-q4_K_M
  2. token-router 클론
    git clone https://github.com/sleeplesshan/token-router.git
cd token-router
    Python 표준 라이브러리만 사용 — 별도 의존성 불필요
  3. 사용 확인
    python3 scripts/router.py heavy_code --file router.py --query "ollama"
  4. (선택) PATH에 등록
    cat > ~/.local/bin/token-router << 'EOF'
#!/bin/bash
OLLAMA_KEEP_ALIVE=0s python3 /path/to/token-router/scripts/router.py "$@"
EOF
chmod +x ~/.local/bin/token-router

안전장치

VRAM 즉시 해제
라우팅 좌표 추출이 끝나는 즉시 로컬 모델을 VRAM에서 해제 (OLLAMA_KEEP_ALIVE=0s)
역방향 맥락 확장
잘라온 코드가 너무 좁으면 클라우드 AI가 스크립트에 “더 넓은 범위를 다시 오려오라”고 역요청하는 프롬프트 안전장치 내장
대용량 파일 스트리밍
5MB 이상 파일은 키워드 + 꼬리 부분을 스트리밍 방식으로 우선 스캔해 메모리 초과 방지
