MengTo/Skills

디자이너이자 개발자 Meng To(Design+Code 창립자)가 만든 에이전트 스킬(Agent Skills) 모음집 — AI 코딩 에이전트가 UI/프론트엔드/애니메이션/자동화 작업을 할 때 불러와 그대로 따라 하는 재사용 가능한 작업 절차서 묶음.

01 · 이게 뭔가

일회성 채팅 답변 대신 버전 관리되는 파일 형태의 작업 지침을 만들어 두는 것이 목적이다. 저장소 철학은 4가지로 요약된다.

1
프롬프트는 자산이다
한 번 잘 나온 프롬프트는 파일로 저장하고 버전 관리한다.
2
스펙이 감(vibe)을 이긴다
명확한 제약과 위계가 일관된 결과를 만든다.
3
레퍼런스가 문단을 이긴다
스크린샷·예시가 폰트·간격·색·리듬을 그대로 전달한다.
4
스킬은 운영 절차서다
언제 쓸지, 먼저 뭘 할지, 기본값과 피할 실수를 알려준다.

02 · 저장소 구조

현재 스냅샷 기준 총 95개 스킬이 4개 카테고리로 나뉘어 있다.

Skills/
  README.md            # 저장소 전체 소개 및 스킬 목록
  CLAUDE.md             # Claude Code용 저장소 작업 가이드
  LICENSE                # MIT
  assets/
  agent-skills/          # 실제 스킬들이 들어있는 곳
    codex/               # 운영/워크플로 스킬 (18개)
    ui/                  # UI 디자인 프롬프팅 스킬 (13개)
    web-design/          # 웹 디자인/구현 스킬 (62개)
    media/               # 이미지 소싱 스킬 (2개)
폴더 계약(folder contract)

각 스킬은 아래 규칙을 따르는 독립 폴더다.

agent-skills/<카테고리>/<스킬-이름>/
  SKILL.md            # 필수: frontmatter + 작업 절차
  REFERENCES.md       # 선택: 링크만 모음
  ARTICLE.md          # 선택: 긴 설명/배경
  assets/             # 선택: 이미지, 템플릿, 예시
  scripts/            # 선택: 보조 스크립트
  • SKILL.md가 에이전트가 실제로 읽고 따르는 본체다. 간결하고 실행 가능하게 유지한다.
  • REFERENCES.md는 링크만 담고, 긴 설명은 넣지 않는다.
  • 스킬은 절차적(단계·패턴·가드레일)이어야 하고 백과사전식이면 안 된다.
  • 트리거는 명시적으로: "Use when..." 형태가 모호한 설명보다 낫다.

03 · SKILL.md 파일 형식

각 SKILL.md는 YAML frontmatter로 시작한다.

---
name: video-to-superprompt
description: Turn a reference video into a super detailed
  recreation or inspiration prompt. Use when...
---

# Video To Superprompt

## Goal
...무엇을 달성하는 스킬인지...

## Workflow
1. 첫 번째로 할 일
2. 두 번째로 할 일

## Pitfalls / 주의점
...
  • name — 스킬 식별자(폴더명과 동일)
  • description — 언제 발동할지 상세히 적는다. 에이전트가 이 문장으로 적용 여부를 판단하므로 트리거 조건이 촘촘히 들어간다.
  • 본문 순서: Goal → Workflow(단계별) → 스니펫/명령어 → 함정/가드레일

04 · 카테고리별 내용

codex/운영·워크플로 · 18개

반복 가능한 실무 작업을 자동화하는 절차서. 대표: video-to-superprompt(참조 영상→초상세 프롬프트), html-to-interaction-prompts, stitched-full-page-capture, playwright, netlify-deploy, copywriting 외.

ui/UI 디자인 프롬프팅 · 13개

디자인 관점의 UI 생성/재설계 방법론. 대표: design-first-ui-prompting(목표→포맷→레이아웃→타입→색→제약), frontend-design, minimalist-ui, image-to-code, redesign-existing-projects 외.

web-design/구현 · 62개 (최대)

실제 랜딩 페이지/모션/3D/스타일을 구현하는 스킬. 하위 그룹:

모션·스크롤 — gsap, marquee-loop, masked-reveal
WebGL·3D — threejs, globe-gl, matterjs
CSS 디테일 — beautiful-shadows, progressive-blur
레이아웃 — editorial-tech, split-layout-technical
비주얼 무드 프리셋 — clean-minimal-beige-light-mode, dark-glass-clean-layout, orange-clean-paper-saas 등 색/분위기별 20여 개
media/이미지 소싱 · 2개

aura-asset-images(스톡풍 디자인/마케팅 이미지), unsplash-asset-images(용도·크롭·비율별 에셋 선택).

05 · 사용법 (에이전트별)

포맷은 순수 마크다운 + 폴더 기반이라 어떤 에이전트에서도 쓸 수 있다.

에이전트사용 방식
Codex작업 전 해당 SKILL.md 로드. 저장소 동작은 AGENTS.md에.
Claude CodeCLAUDE.md에서 참조하거나 ~/.claude/skills/로 복사해 정식 스킬로 등록.
Cursor규칙이나 채팅 컨텍스트를 특정 스킬 폴더로 지정.
기타가장 좁게 매칭되는 스킬을 먼저 읽고 단계·레퍼런스를 따른다.
대표 워크플로 (플래그십)
영상 → video-to-superprompt → HTML 원샷 생성 → html-to-interaction-prompts로 인터랙션 재활용 → stitched-full-page-capture로 전체 페이지 레퍼런스 확보 → daily-ui-inspiration-capture로 루프화.

06 · 새 스킬 추가 방법

  1. 폴더 생성: agent-skills/<카테고리>/<스킬-이름>/
  2. SKILL.md 작성: frontmatter(name, description) + 언제 쓸지/워크플로/함정/레시피
  3. (선택) REFERENCES.md: 문서 링크만
  4. 계약 점검: 명확한 트리거 / 구체적 워크플로 / 재사용 스니펫 / 함정·수용 기준 / 비밀정보 없음
  5. 커밋: 스킬 단위 작은 커밋 — Add <스킬명> skill

작성 스타일: 훑어보기 쉽고 실용적이고 자신감 있게. 제약과 기본값(지속시간·간격·위계·명령어) 우선. 군더더기 배제. 긴 설명은 ARTICLE.md, 링크는 REFERENCES.md로 분리.
